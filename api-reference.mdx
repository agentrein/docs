AgentRein provides two types of API reference:

- **SDK methods** for using AgentRein from your application.
- **REST API** for managing AgentRein resources over HTTP. See the [REST API specification](https://agentrein.com/docs/api-reference/openapi.json).

## Shared REST response convention

Successful REST API responses use the following envelope. Errors use RFC-7807 problem-details.

<ResponseField name="response" type="object">

  <ResponseField name="data" type="object">

  The endpoint result.

  </ResponseField>

  <ResponseField name="error" type="null">

  `null` for a successful response.

  </ResponseField>

  <ResponseField name="timestamp" type="string">

  The time the response was generated.

  </ResponseField>

</ResponseField>

## `wrap<T>`

Wrap a standard SDK client to enable automatic logging, interception, and rollbacks.

**Signature:**  
```ts
wrap<T extends object>(client: T, session: Session, options: WrapOptions): T
```

- `client`: The standard SDK instance (e.g., `octokit`).
- `session`: The active agent session object.
- `options`: A `WrapOptions` object including the `connector` identifier.

**Returns:**  
A recursive Proxy of the original client (`T`), ensuring 100% type preservation.

Where `WrapOptions` is:
```ts
{
    connector: string;
    requiresApproval?: string[];
    retryable?: string[];
    pollIntervalMs?: number;
    timeoutMs?: number;
}
```
