## Credentials

Add connector credentials in **Dashboard → Integrations**. Each credential has a Key (the token name below) and a Value (Plain Text or JSON).

<Tabs>
  <Tab title="GitHub" icon="github">
    **Key:** `GITHUB_TOKEN`
    **Type:** Plain Text

    Get your token at: [GitHub → Settings → Developer settings → Personal access tokens](https://github.com/settings/tokens)
  </Tab>

  <Tab title="Slack">
    **Key:** `SLACK_TOKEN`
    **Type:** Plain Text

    Get your token at: [Slack API → Your Apps → OAuth & Permissions → Bot Token](https://api.slack.com/apps)
  </Tab>

  <Tab title="Stripe">
    **Key:** `STRIPE_TOKEN`
    **Type:** Plain Text

    Get your key at: [Stripe Dashboard → Developers → API keys → Secret key](https://dashboard.stripe.com/apikeys)
  </Tab>

  <Tab title="HubSpot">
    **Key:** `HUBSPOT_TOKEN`
    **Type:** Plain Text

    Get your token at: [HubSpot → Settings → Integrations → Private Apps](https://app.hubspot.com/private-apps)
  </Tab>

  <Tab title="Salesforce">
    **Key:** `SALESFORCE_TOKEN`
    **Type:** Plain Text

    Get your token at: [Salesforce → Settings → Personal → Reset My Security Token](https://help.salesforce.com/s/articleView?id=sf.user_security_token.htm)
  </Tab>

  <Tab title="Notion">
    **Key:** `NOTION_TOKEN`
    **Type:** Plain Text

    Get your token at: [Notion → Settings → Connections → Develop or manage integrations](https://www.notion.so/my-integrations)
  </Tab>

  <Tab title="Gmail">

    **Required scope:** `https://www.googleapis.com/auth/gmail.modify`
  </Tab>

  <Tab title="Google Drive">

## Validating Credentials Before Execution

Call `validateConfig()` during agent startup:

```ts
const result = await agentrein.validateConfig(['github', 'slack']);

if (!result.valid) {
  console.error('Missing credentials:', result.missing);
  process.exit(1);
}
```
